# ShopXO 商城系统 Bug 列表

## BUG001：添加商品后弹窗提示数量与实际购物车数量不一致

| 字段 | 内容 |
| :--- | :--- |
| **Bug编号** | BUG001 |
| **所属模块** | 购物车 |
| **严重程度** | 中 |
| **状态** | 待修复 |
| **发现时间** | 2026-10-10 |

### 复现步骤

1. 登录商城（账号 qqqqqq / 密码 qqqqqq）
2. 打开任意商品详情页
3. 点击「加入购物车」
4. 观察弹窗提示的商品件数
5. 点击右上角购物车图标，进入购物车页面
6. 观察实际商品件数

### 预期结果

弹窗提示的商品件数，应与购物车页面中实际显示的件数一致。

### 实际结果

弹窗显示「购物车共 6 件商品」，但购物车页面实际只有 5 件商品。

### 缺陷分析

该问题属于前后端数据不一致。弹窗提示的购物车数量取自后端返回的总数，而购物车列表只显示了当前有效商品，导致数量差异。

### 建议

前端在弹出提示时，应以实际拉取的购物车列表数据为准，而不是直接使用后端返回的总数。
