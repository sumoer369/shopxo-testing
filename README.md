# ShopXO 商城系统 测试实战

## 项目简介
对 ShopXO 商城系统（https://d2.shopxo.vip/）进行功能测试，覆盖登录、搜索、购物车、订单四大模块。

## 测试内容
- **黑盒测试**：等价类、边界值、场景法设计32条用例
- **SQL校验**：使用Navicat连接MySQL模拟数据库，验证数据一致性
- **日志排查**：使用Linux命令（grep、tail）分析模拟日志
- **缺陷管理**：提交并跟踪1个有效缺陷

## 项目结构
- `testcases/`：测试用例与缺陷记录（Markdown）
- `测试报告.md`：完整的测试报告文档
- `README.md`：项目说明文档

## 测试结论
共执行32条用例，通过31条，发现1个数据不一致缺陷。

## 使用工具
- **测试用例**：Markdown
- **数据库**：MySQL（Navicat）
- **日志排查**：Linux命令（grep、tail、cat）
- **缺陷管理**：Markdown
